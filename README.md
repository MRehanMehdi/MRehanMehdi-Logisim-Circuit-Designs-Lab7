# Digital Logic Circuits using Logisim

This repository contains basic digital logic circuits designed using **Logisim**, a graphical tool for designing and simulating logic circuits. These circuits are commonly used in digital logic and computer organization courses.

## Contents

The repository includes circuit diagrams for the following components:

- ✅ AND Gate  
- ✅ OR Gate  
- ✅ NOT Gate  
- ✅ NAND Gate  
- ✅ NOR Gate  
- ✅ XOR Gate  
- ✅ Multiplexer (MUX)  
- ✅ Demultiplexer (DEMUX)  
- ✅ Encoder  
- ✅ Decoder
- ✅ Half Adder
- ✅ Full Adder
